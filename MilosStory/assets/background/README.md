# Background Image

Place any image file in this folder to use as the background for both the title screen and save slot selection screen.

## Supported Formats
- PNG (.png)
- JPEG (.jpg, .jpeg)
- BMP (.bmp)
- GIF (.gif)

## How It Works
- The first image file found in this folder will be used
- The image will be automatically scaled to fit the screen (1200x800)
- The same background is used for both the title screen and save selector
- If no image is found, default backgrounds will be used
